# 📐 Calculadora Pós-Fixada – Projeto de Estrutura de Dados

Este projeto é uma calculadora desenvolvida em Java que interpreta e resolve expressões na notação pós-fixada (também chamada de notação polonesa reversa), utilizando estrutura de dados como **fila dinâmica** e **pilha**.
    A aplicação possui interface gráfica com Java Swing

## 🚀 Como Executar

```bash
git clone https://github.com/ramlin-ctrl/CalculadoraPosFixada
cd CalculadoraPosFixada
javac view/Main.java
java view.Main



🔍 Validações Implementadas

    ✅ Detecção de divisão por zero

    ✅ Operadores inválidos

    ✅ Expressões malformadas

    ✅ Gerenciamento correto de fila e pilha
